# Jmokut's CF Daily Practice 

This repository contains Python scripts that fetch daily Codeforces practice problems.  
They are configured for different regions (Nigeria and Russia) to match local time zones.

---

## Files
- **CFDailyPracticeNGA.py** → Nigeria (West Africa Time)
- **CFDailyPracticeRUS.py** → Russia (Moscow Time)

---

## Requirements
- Python **3.7.3** (recommended version to avoid compatibility issues)
- Install dependencies:
  ```bash
  pip install requests
  ````

---

## Usage

1. Copy the raw script from GitHub.
2. Run with Python:

   ```bash
   python CFDailyPracticeNGA.py
   ```

   or

   ```bash
   python CFDailyPracticeRUS.py
   ```

---

## Notes

* The **Nigerian script** uses **Nigeria Standard Time (WAT)**.
* The **Russian script** uses **Moscow Time (MSK)**.
* Make sure your system clock is correct to avoid scheduling issues.

---

## Troubleshooting

* If you encounter errors:

  1. Double-check you are using **Python 3.7.3**.
  2. Ensure you have installed `requests`.
